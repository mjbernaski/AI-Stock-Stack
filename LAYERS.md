# AI & Technology Stock Stack - Layer Structure

This index tracks publicly traded companies organized into five layers (0 through 4) representing the technology value chain, from base power infrastructure up to consumer-facing applications.

The base power layer required to run massive AI data centers.

|--------|---------|------|

## How to Read This

The layers flow bottom-up: Layer 0 powers Layer 1, which enables Layer 2, which enables Layer 3, which enables Layer 4. A shift in the foundation (e.g., power constraints, new chip architectures, supply disruptions) ripples upward through the entire stack.

The index tracks total market cap across all layers and visualizes how capital is distributed between them over time.

## Suggesting New Companies

When suggesting additions, consider:
- Does the company clearly fit one layer, or does it span multiple? (Prefer companies with a clear primary layer)
- Is it publicly traded with a reliable ticker?
- Does it represent a meaningful part of the AI/technology value chain?
- Would it overlap significantly with an existing company's role?
