# AI & Technology Stock Stack - Layer Structure

This index tracks publicly traded companies organized into four layers that mirror the technology value chain, from physical infrastructure up to consumer-facing applications.

## Layer 1: Foundation (Semiconductors & Materials)

The base layer of the technology stack - companies that manufacture chips, produce semiconductor equipment, and supply the raw materials/fabrication that everything else is built on.

| Ticker | Company | Role |
|--------|---------|------|
| TSM | TSMC | Leading-edge chip fabrication (foundry) |
| ASML | ASML | Lithography equipment (EUV monopoly) |
| MU | Micron | Memory chips (DRAM, NAND) |
| AMAT | Applied Materials | Semiconductor manufacturing equipment |
| LRCX | Lam Research | Wafer fabrication equipment (etch, deposition) |

## Layer 2: Compute & Logic (Chip Design & Infrastructure Hardware)

Companies that design the processors, accelerators, and hardware systems that provide computing power - built on Layer 1's fabrication capabilities.

| Ticker | Company | Role |
|--------|---------|------|
| NVDA | Nvidia | GPU/AI accelerator design |
| AVGO | Broadcom | Networking, custom silicon, infrastructure chips |
| AMD | AMD | CPU/GPU design |
| QCOM | Qualcomm | Mobile/edge processors |
| DELL | Dell | Servers, workstations, infrastructure hardware |
| VRT | Vertiv | Data center power/cooling infrastructure |

## Layer 3: Cloud & Data (Platforms & Services)

Cloud providers and enterprise platforms that run on Layer 2 hardware, providing the scalable compute, storage, and data services that applications depend on.

| Ticker | Company | Role |
|--------|---------|------|
| MSFT | Microsoft | Azure cloud, enterprise software |
| GOOGL | Alphabet | Google Cloud, search, AI services |
| AMZN | Amazon | AWS cloud infrastructure, e-commerce |
| ORCL | Oracle | Cloud databases, enterprise infrastructure |

## Layer 4: Interface & App (Consumer & Enterprise Applications)

The top layer - companies building the products, platforms, and experiences that end users interact with, powered by the layers below.

| Ticker | Company | Role |
|--------|---------|------|
| AAPL | Apple | Consumer devices, ecosystem |
| META | Meta | Social platforms, VR/AR |
| TSLA | Tesla | EVs, autonomous driving, energy |
| TCEHY | Tencent | Gaming, messaging, fintech (China) |
| PLTR | Palantir | Data analytics, government/enterprise AI |
| CRM | Salesforce | CRM, enterprise SaaS |
| ADBE | Adobe | Creative/document software |
| NOW | ServiceNow | IT workflow automation |

## How to Read This

The layers flow bottom-up: Layer 1 enables Layer 2, which enables Layer 3, which enables Layer 4. A shift in the foundation (e.g., new chip architectures, supply constraints) ripples upward through the entire stack.

The index tracks total market cap across all layers and visualizes how capital is distributed between them over time.

## Suggesting New Companies

When suggesting additions, consider:
- Does the company clearly fit one layer, or does it span multiple? (Prefer companies with a clear primary layer)
- Is it publicly traded with a reliable ticker?
- Does it represent a meaningful part of the AI/technology value chain?
- Would it overlap significantly with an existing company's role?
